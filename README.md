# TrawlForm---Parametric-boat-design
Diseño preliminar de embarcaciones automatizando Maxsurf 2025 desde Python (COM). Calcula hidrostáticas, genera variantes escaladas del casco y obtiene resistencia y potencia con los métodos de Maxsurf Resistance (Savitsky, Holtrop, Van Oortmerssen…), con informes, Excel y gráficas. Manual de uso en castellano.
